# Roadmap

| Version | Theme | Ships |
|---------|-------|-------|
| **v1** (current) | Core probe | Shared engine, CLI, API, Next waterfall, SLO, redirects, architecture diagrams, pattern docs |
| **v2** | History | SQLite repository adapter, history UI + `hoptrace history` |
| **v3** | Saved probes | Named templates, library UI, `hoptrace run <name>` |
| **v4** | Live progress | Observer events, WebSocket stream, compare runs |
| **v5** | Schedules | Cron worker, baselines, p50/p95 regression |
| **v6** | Auth | API keys / OIDC, workspaces |
| **v7** | Alerting | Webhooks / Slack notifier strategies |
| **v8** | Plugins | Exporter/resolver extension SDK |
| **v9** | Scale | Postgres adapter, quotas, OpenAPI SDK, release automation |
