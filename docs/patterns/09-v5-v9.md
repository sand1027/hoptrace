# v5–v9 patterns

## v5 Template Method — scheduler
`schedule.Worker` ticks on an interval, selects due jobs, runs, persists, notifies.
Override behavior via injected `Runner` / `OnComplete`.

## v6 Decorator — auth middleware
`auth.Middleware` wraps the HTTP handler chain. When API keys exist, requests need
`Authorization: Bearer ht_...` or `X-API-Key`. Workspace id is stored in context.

## v7 Strategy + Null Object — notifiers
`notify.Notifier` with `WebhookNotifier`, `SlackNotifier`, `MultiNotifier`, `NoopNotifier`.
SLO failures and hard errors emit alerts and are recorded in `failures`.

## v8 Open/Closed — plugin registry
`plugin.RegisterExporter(name, factory)` extends `export.Factory` without editing core switches.
See `examples/exporterplugin/README.md` and built-in `jsonl`.

## v9 Adapters + limits
- `repository.PostgresRepository` implements the same `ProbeRepository` interface
- `ratelimit.Middleware` token-bucket per workspace
- `openapi.yaml` contract
- Share links: `POST /v1/probes/{id}/share` → public `GET /v1/share/{token}`

Set `DATABASE_URL` and call `repository.OpenPostgres` when wiring a Postgres deploy.
